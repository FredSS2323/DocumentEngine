# DocumentEngine

Biblioteca desenvolvida em .NET para geração de documentos em PDF de forma simples, reutilizável e extensível.

## Objetivo

O objetivo deste projeto é servir como base para aplicações que necessitam gerar documentos como:

- Recibos
- Contratos
- Certificados
- Relatórios
- Orçamentos

A ideia é evitar recriar a lógica de geração de documentos em cada novo projeto.

---

## Tecnologias

- .NET 10
- C#
- QuestPDF
