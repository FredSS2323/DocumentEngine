# Contribuindo

Obrigado pelo interesse em contribuir.

## Padrão de commits

Utilizamos o padrão Conventional Commits.

Exemplos:

- feat:
- fix:
- docs:
- refactor:
- test:
- chore:

## Estrutura

- src → código da biblioteca
- tests → testes automatizados
- docs → documentação

## Pull Requests

Toda nova funcionalidade deve possuir testes quando aplicável.
